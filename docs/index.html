In one breath

The rule

Rust displays; TypeScript decides. The compositor draws and routes input. Every decision is the shell's, sent over IPC.

The UI

TypeScript defines it; mirin Metal draws it. Every surface is React through @mirinjs/metal, drawn natively by GPUI.

The look

Borrow the best of both; belong to neither. A Mac's menu bar and glass, Windows' snapping and taskbar, Dashi's own Shapes and ingredients.

Keeping these pages true

  • They are source of truth for the brand and the design (design.html): a change to a color, a measure, or a motion lands in the code and here in the same commit.
  • Values on these pages are read from the code (each section names its file). If they disagree, the code is what ships; fix the page, or fix the code and the page together.
  • Plain HTML, CSS, and a little JavaScript in docs/assets/. No build step, nothing fetched from the network. Open any page straight from disk.
  • Things still undecided are marked open. They are questions, not rules.
